# EVABOT ONLINE // Спецификация Терминального Интерфейса (TUI)

## 1. Фундаментальные принципы дизайна
- **Акцент на текст и информацию**: Ноль декоративных рамок (`┌─┐`, `│`, `└─┘`), разделителей и визуального мусора.
- **Шрифт и размер**: Единый `font-family: 'Roboto Mono', 'Roboto', monospace` и строгий размер `16px` абсолютно везде.
- **Цветовая палитра**:
  - База: Строгий черно-белый контраст (глубокий чёрный `#000000`, чистый белый `#ffffff`, приглушённый серый `#777777`).
  - Сигналы: Строго 3 цвета (светофор):
    - 🟢 Зеленый (`#00e676`): Норма, онлайн, успех, свободный тариф `[FREE]`, пинг < 150ms.
    - 🟡 Желтый (`#ffd600`): Ожидание, генерация, занят, платный тариф `[PAID]`, пинг 150–300ms.
    - 🔴 Красный (`#ff1744`): Ошибка, сбой, оффлайн `[OFFLINE]`, пинг > 300ms.
- **Закрепленная строка ввода**: Строка `> █` всегда зафиксирована внизу экрана (sticky bottom), диалог скроллится над ней.
- **Единый вид**: 100% идентичное построчное отображение в веб-браузере (cyber-terminal) и в CLI (консоль, SSH, curl).

## 2. Построчная структура экрана

```text
● EvaBot v0.0.1  ONLINE  135ms
Модель: gemini-2.5-flash [FREE]  Режим: solo  Пул: 78 моделей (/models)
Команды: /help  /?  /top  /models  /mode  /consilium  /clear
Базы данных: Chroma Vector (1075 эмбеддингов) [OK] · SQLite FTS5 (1086 чанков) [OK] · Memory KB (178 док) [OK]
Метрики: Core(Frankfurt) CPU 1.2% RAM 4.3/32GB | Edge(Iowa) Load 0.08 RAM 439MB | Mesh 123ms RTT [OK]

[19:10:00] system : Подключено к нейроядру evabot.online (Frankfurt)
[19:10:15] user   : привет
[19:10:16] evabot : Привет! Я EvaBot. Чем могу помочь?

> █
```

### Детализация строк:
1. **Строка 1 (Хедер и индикатор)**:
   - `●` — один круглый индикатор статуса (зеленый / желтый / красный).
   - `EvaBot v0.0.1` — имя проекта и версия (белый).
   - `ONLINE` — текстовый статус (зеленый).
   - `135ms` — динамический реальный пинг (зеленый/желтый/красный).
2. **Строка 2 (Конфигурация ядра)**:
   - `Модель: <id> [FREE/PAID]` — текущая активная модель (авто-выбор самой умной бесплатной `gemini-2.5-flash`).
   - `Режим: solo / consilium` — интерактивный переключатель режима.
   - `Пул: 78 моделей (/models)` — общее число моделей и команда каталога.
3. **Строка 3 (Командный справочник)**:
   - `Команды: /help  /?  /top  /models  /mode  /consilium  /clear` — список доступных системных команд.
4. **Строка 4 (Подключенные базы данных)**:
   - `Базы данных: Chroma Vector (1075 эмбеддингов) [OK] · SQLite FTS5 (1086 чанков) [OK] · Memory KB (178 док) [OK]`
5. **Строка 5 (Живые метрики серверов кластера)**:
   - `Метрики: Core(Frankfurt) CPU X% RAM X/32GB | Edge(Iowa) Load X.XX RAM XMB | Mesh Xms RTT [OK]`
6. **Строка 6**: Пустая строка (воздух).
7. **Строки 7...N (Поток сообщений)**:
   - `[HH:MM:SS]` — метка точного времени (серый).
   - `<роль> :` — отправитель (`system`, `user`, `evabot`, `[КОНСЕНСУС]`).
   - `<текст>` — текст сообщения (белый, чистый текст с переносами).
8. **Внизу (Закрепленная строка ввода)**:
   - `> █` — курсор ввода команд или диалога, всегда закрепленный у нижнего края экрана.
