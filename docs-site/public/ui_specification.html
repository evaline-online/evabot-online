EVABOT ONLINE // Спецификация Построчного Линейного Интерфейса (Linear Stream Interface — LSI)

Версия спецификации: 2.1.0 (2026-09-14)
Статус: Действующий промышленный стандарт интерфейсов EvaBot
Архитектурная цель: 100% адаптивный, резиновый, построчно выверенный интерфейс без мусора, скачков и паразитных отступов, функционирующий одинаково идеально в любом терминале (CLI/ANSI) и в любом веб-браузере (мобильном и десктопном).

1. Фундаментальная концепция LSI (Linear Stream Interface)

В отличие от традиционных перегруженных веб-приложений, интерфейс EvaBot строится как дискретный линейный поток строк (Linear Stream). Каждый блок информации — это строго квантованная последовательность строк:

  1. Единый поток чтения сверху вниз: Пользователь воспринимает диалог как непрерывную ленту консоли.
  2. Изолированный скроллинг чата: Отправка сообщений и потоковый ответ AI (SSE Stream) вызывают скролл только внутри контейнера чата (chatContainer.scrollTop = chatContainer.scrollHeight). Окно браузера (window.scrollTo) строго зафиксировано на Экране 1 и никогда самопроизвольно не скроллится на Экран 2.
  3. Строгий левый край (Flush Left, Indent 0px): Никаких ступенчатых отступов на первой строке ответа. Метаданные (время, автор) вынесены в отдельную мета-строку над текстом, благодаря чему тело сообщения начинается строго с левой границы контейнера.

2. Анатомия двух экранов (Two-Screen Topology)

Интерфейс разделен на два взаимосвязанных экрана, переключение между которыми осуществляется плавным скроллингом без выпадающих модальных шторок:

3. Три режима отображения (Triple UI Mode Strategy)

В настройках на Экране 2 пользователю доступен мгновенный переключатель между тремя визуальными режимами:

Режим 1: [ NOCSS ] (Raw Stream / Чистый текст)

  • Назначение: Терминалы без графики, мобильные браузеры при экстремально медленном интернете (2G/GPRS/Edge), скринридеры для незрячих, текстовые браузеры (lynx, links, w3m, curl).
  • Поведение: Отключает все таблицы стилей <style> и <link rel="stylesheet"> (через media="not all").
  • Свойства:
    • Ноль килобайт CSS-овеschema, 100% нативная скорость парсинга DOM.
    • Модальные окна (#model-modal) имеют атрибут style="display:none;", исключающий засорение текстового потока.
    • Текст и команды строго следуют линейной последовательности HTML5.

Режим 2: [ TUI / ТЕРМИНАЛ ] (Cyber-Terminal Monospace)

  • Назначение: Программисты, системные инженеры, любители киберпанка и классической UNIX-консоли.
  • Поведение: Активирует атрибут data-mode="term".
  • Свойства:
    • Шрифт строго моноширинный: 'Roboto Mono', monospace.
    • Цветовая палитра: глубокий черный фон #000000, неоновый зеленый #00e676, предупреждающий желтый #ffd600, аварийный красный #ff1744, акцентный циан #00d8ff.
    • Псевдографические ASCII-рамки (┌─┐, │, └─┘, ■□□).
    • Кнопки оформлены в квадратных скобках: [≡], [▶], [↵], [🎙], [1x].
    • Метаданные сообщения компактны: evabot : [19:10:00].

Режим 3: [ WEB / СОВРЕМЕННЫЙ ] (Modern Mobile-First Web)

  • Назначение: Повседневное использование на смартфонах, планшетах и ноутбуках по высшим современным стандартам UI/UX.
  • Поведение: Активирует атрибут data-mode="web".
  • Свойства:
    • Шрифт сообщений: плавный и читаемый без засечек (Roboto, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif), межстрочный интервал 1.55.
    • Моноширинный шрифт сохраняется исключительно внутри блоков кода, бейджей и телеметрии.
    • Сообщения-карточки (Bubbles):
      • Ответ бота (.msg-evabot): карточка с полупрозрачным фоном rgba(12, 18, 28, 0.88), матовым размытием backdrop-filter: blur(12px) и фирменной изумрудной полосой слева border-left: 3.5px solid var(--green).
      • Сообщение пользователя (.msg-user): выравнивается по правому краю (align-self: flex-end) с легким изумрудным градиентом.
      • Системное уведомление (.msg-system): центрированная полупрозрачная плашка с золотистым пунктирным контуром.
    • Строка ввода: скругленная капсула (border-radius 16px) с размытием фона и увеличенными тач-зонами кнопок.

4. Грамматика строк (Line Grammar Specification)

Каждый элемент в потоке подчиняется строгим правилам разметки:

Тип строкиDOM-селекторОписание и поведение
Logo Bar.header-minimalВерхняя строка Экрана 1. Слева: точка статуса ● + имя ядра. Справа: кнопка-бургер [≡].
Meta Line.msg-metaВерхняя строка сообщения. Содержит .msg-sender (жирный цветной бейдж) и .msg-time (серый timestamp).
Content Body.msg-bodyТело ответа. margin: 0; padding: 0; width: 100%;. Стартует строго с 0px отступа. Поддерживает markdown, списки, ссылки, жирный текст.
Code Fence Header.code-headerВерхняя рамка блока кода. Слева: язык (PYTHON, TYPESCRIPT). Справа: интерактивная кнопка [COPY].
Code Content.code-content preТело кода. Горизонтальный скролл при переполнении, сохранение табуляции и отступов.
Voice Bar.msg-voice-barНижняя сервисная строка сообщения: [▶ Speak], [⏸ Pause], [■ Stop], [1x], [📋 Copy], [⬇ MP3], визуализатор [ ▂▃▅▆▇▆▅▃▂ ].
Prompt Input.input-lineЗакрепленная строка ввода. Префикс >, многострочный расширяемый textarea, кнопки [↵] и [🎙].

5. Резиновая адаптивность (Fluid / Elastic Viewport Engine)

Интерфейс спроектирован так, чтобы без горизонтального скролла и искажений заполнять экраны любого размера:

1. Смартфоны в портретной ориентации (Portrait: 320px – 480px)

  • Контейнер чата занимает 100% доступной ширины за вычетом безопасных зон (env(safe-area-inset-*)).
  • Высота зафиксирована через 100dvh — динамическая высота окна предотвращает сдвиги элементов при скрытии/появлении адресной строки браузера.
  • Высота шапки — 36px–38px.
  • Тач-зоны кнопок ввода и навигации составляют не менее 40–44px для безошибочного нажатия пальцем.

2. Смартфоны в горизонтальной ориентации (Landscape: высота < 540px)

  • Активируется специальный медиа-запрос:

  • Шапка сжимается до 26px в высоту, вторичный подзаголовок скрывается, освобождая драгоценные пиксели по вертикали.

  • Паддинги сообщений уменьшаются до 4px 8px, поле ввода сжимается до 28px.

  • Пользователь видит одновременно 3–4 полных сообщения даже при открытой виртуальной клавиатуре.

  • На Экране 2 плитки настроек автоматически встают в двух- и трехколоночную сетку (grid-template-columns: repeat(auto-fit, minmax(180px, 1fr))).

3. Планшеты, ноутбуки и 4K-мониторы (600px – 3840px)

  • В режиме web ширина ленты чата плавно масштабируется и ограничивается комфортной для чтения шириной max-width: 880px; margin: auto;.
  • Строка ввода и шапка центрируются строго по ширине ленты чата.
  • Никаких перекосов влево или паразитных пустот.

4. Терминал (CLI / POSIX ANSI Stream)

  • При запросе через curl https://evabot.online | sh или запуск src/cli/terminal-chat.ts сервер автоматически вычисляет ширину терминала (process.stdout.columns или переменная окружения $COLUMNS).
  • Автоматический перенос строк по границам слов (word wrap).
  • Поддержка 256-цветной и 16-цветной деградации ANSI escape-последовательностей.
