# Інструкція користувача EvaBot: CLI та Web

**Версія:** 0.2.0  
**Стандарти розрахунків:** Виключно долари США ($) та євро (€)  

---

## 1. Підготовка та налаштування ключа API

EvaBot використовує моделі Google Gemini за підпискою Google AI Pro.
Вказати API-ключ Gemini можна будь-яким із трьох способів:
1. **Змінна оточення:** Виконайте команду `export GEMINI_API_KEY="ваш_ключ"` у терміналі.
2. **Конфігураційний файл:** Створіть файл `.env` у корені проєкту:
   ```env
   GEMINI_API_KEY="ваш_ключ"
   DEFAULT_MODEL="gemini-2.5-flash"
   PORT=3000
   ```
3. **Налаштування у веб-інтерфейсі:** Натисніть кнопку **API Key** у верхньому меню сайту та збережіть ключ у локальному сховищі браузера.

## 2. Запуск у терміналі (режим CLI)

### Інтерактивний діалоговий режим
Запустіть інтерактивний чат у консолі:
```bash
npm run cli
```

Доступні слеш-команди:
- `/models`: Переглянути список підтримуваних моделей Gemini.
- `/model <id>`: Перемкнути активну модель (наприклад, `/model gemini-2.5-pro`).
- `/key <ключ>`: Встановити або оновити ключ API для поточної сесії.
- `/system <інструкція>`: Змінити системну підказку або роль помічника.
- `/clear`: Очистити історію поточної розмови.
- `/history`: Переглянути кількість повідомлень у пам'яті.
- `/help`: Вивести довідку по командах.
- `/exit` (або `exit`): Вийти з програми.

### Одноразовий запит через аргументи
Для надсилання запиту без входу в інтерактивний цикл:
```bash
npx tsx src/cli/terminal-chat.ts --prompt "Коротко поясни принципи квантових обчислень" --model "gemini-2.5-flash"
```

## 3. Запуск веб-сервера та браузерного інтерфейсу

Запуск сервера:
```bash
npm start
```
Відкрийте `http://localhost:3000` у вашому браузері (або `https://evabot.online` на сервері).

### Можливості веб-інтерфейсу:
1. **Перемикач моделей:** Швидкий вибір між `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash` та `gemini-1.5-pro`.
2. **Потокова генерація в реальному часі:** Відображення відповідей без затримок.
3. **Форматування Markdown та підсвічування коду:** Акуратні списки, таблиці та кнопки швидкого копіювання коду **Copy**.
4. **Безпечне збереження ключа:** Ключ Google AI Pro зберігається в `localStorage` браузера користувача.

## 4. Автоматичне тестування

Запуск пакету автотестів:
```bash
npm test
```
Тести перевіряють роботу реєстру моделей, пам'ять діалогів, статус ендпоінтів сервера та дотримання фінансових правил проєкту.
