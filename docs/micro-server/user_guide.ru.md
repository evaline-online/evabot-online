# Руководство пользователя EvaBot: CLI и Web

**Версия:** 0.2.0  
**Стандарты расчетов:** Исключительно доллары США ($) и евро (€)  

---

## 1. Подготовка и настройка ключа API

EvaBot использует модели Google Gemini по подписке Google AI Pro.
Задать API-ключ Gemini можно любым из трех способов:
1. **Переменная окружения:** Выполните `export GEMINI_API_KEY="ваш_ключ"` в терминале.
2. **Файл конфигурации:** Создайте файл `.env` в корне проекта:
   ```env
   GEMINI_API_KEY="ваш_ключ"
   DEFAULT_MODEL="gemini-2.5-flash"
   PORT=3000
   ```
3. **Настройки в веб-интерфейсе:** Нажмите кнопку **API Key** в верхней панели сайта и сохраните ключ в локальном хранилище браузера.

## 2. Запуск в терминале (режим CLI)

### Интерактивный режим диалога
Запустите интерактивный чат в терминале:
```bash
npm run cli
```

Доступные слэш-команды внутри терминала:
- `/models`: Показать список поддерживаемых моделей Gemini.
- `/model <id>`: Переключить активную модель (например, `/model gemini-2.5-pro`).
- `/key <ключ>`: Установить или обновить ключ API для текущей сессии.
- `/system <инструкция>`: Изменить системную подсказку/роль ассистента.
- `/clear`: Очистить историю сообщений текущего диалога.
- `/history`: Показать число сообщений в истории.
- `/help`: Вывести справку по командам.
- `/exit` (или `exit`): Завершить работу с чатом.

### Одноразовый запуск через аргументы командной строки
Для выполнения разовых запросов из скриптов или терминала:
```bash
npx tsx src/cli/terminal-chat.ts --prompt "Кратко опиши принципы квантовых вычислений" --model "gemini-2.5-flash"
```

## 3. Запуск веб-сервера и браузерного интерфейса

Запуск локального сервера:
```bash
npm start
```
Затем перейдите по адресу `http://localhost:3000` в вашем веб-браузере (или `https://evabot.online` при развертывании на микросервере).

### Возможности веб-интерфейса:
1. **Переключатель моделей:** Моментальный выбор между `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash` и `gemini-1.5-pro`.
2. **Потоковый вывод в реальном времени:** Токены поступают по мере генерации.
3. **Форматирование Markdown и подсветка кода:** Поддержка списков, таблиц и блоков кода с кнопкой быстрого копирования **Copy**.
4. **Локальное хранение ключа:** Ключ Google AI Pro хранится в браузере и не передается третьим лицам.

## 4. Автоматическое тестирование

Запуск пакета автотестов:
```bash
npm test
```
Тесты проверяют реестр моделей, сохранение контекста диалога, эндпоинты сервера и соблюдение финансовых правил проекта.
