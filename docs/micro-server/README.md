# Микро-сервер (Iowa) — Архив документации

Этот каталог содержит документацию, сведённую с микро-сервера EvaBot (`100.125.200.49`), которая не присутствует в основном репозитории `docs/` или представлена в других версиях/локализациях.

## Содержание

- `architecture/` — локализованные архитектурные спецификации (EN/RU/UK)
- `audit/` — отчёты аудита и диагностики (EN/RU/UK)
- `knowledge-base/` — гибридная база знаний EvaLine (177 md на 6 языках)
- `company-dossier/` — досье компании EvaLine
- `pages/` — доменные спецификации (.unui.md)
- `legacy-ui/` — архив UI v1 (en/uk/ru)
- `frontend/` — файлы frontend (TESTING.md)
- `user_guide.{en,ru,uk}.md` — руководства пользователя
- `audit_and_diagnosis.{en,ru,uk}.md` — отчёты аудита
- `GLOSSARY.md` — глоссарий терминов

## Как использовать

Эти файлы доступны для справки и исторического контекста. Актуальная архитектура системы описана в:
- `architecture/EVALINE_EVABOT_CAPABILITIES_MANIFESTO.md`
- `architecture/GOOGLE_ECOSYSTEM_AGENT_FACTORY_ARCHITECTURE.md`

Последние обновления с микро-сервера происходят через скрипт `docs-central.sh` (шаг `[4/7] docs/ → micro-server`).
