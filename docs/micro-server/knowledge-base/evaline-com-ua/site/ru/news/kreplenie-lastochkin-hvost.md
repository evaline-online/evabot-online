# Крепление «Ласточкин хвост»

10.03.2014

Крепление «ласточкин хвост» по краям татами позволяют собрать покрытие любой площади и конфигурации, а хорошее соединение исключают щелей между матами.

Тепловые и хорошие амортизационные свойства позволяют использовать покрытия EvaLine на бетонном, кафельном и других видов полах, что обезопасит спортсменов от травм. Напольные покрытие EvaLine стойко к влаге, легко чистится и моется

Маты Татами с креплением ласточкин хвост предназначены для напольного покрытия в спортивных залах, фитнес залах, игровых, детских комнатах, тренировочных площадок.

Они пользуются большой популярностью среди матов на пол, потому что они очень эластичные и мягкие,что дает возможность сгладить болевые ощущения при падении.
