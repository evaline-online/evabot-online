# Производство EVA (ЭВА) листов для оптовых покупателей

EVA (ЭВА) листы — это хороший материал для костюмов и других аксессуаров ручной работы (к таким относятся костюмы для косплей, крафта, различные бутафорные костюмы, декорации).

ЕVA — это экологически чистый вспененный этиленвинилацетат — композиционно полимерный материал, относящийся к полиолефинам.

![](https://evaline.com.ua/images/x1.1b2b.jpg.pagespeed.ic._uXpqEEWCJ.jpg)

### Широкая цветовая гамма

Все позиции имеют широкую цветовую гамму, что позволит Вам идеально подобрать материал.

### Преимущества данного материала

  * Материал отличается легкостью (пористая структура), высокой прочностью на разрыв в массе, гибкостью
  * Термопластичен - при нагреве сохраняет придаваемую форму, без разрушения своей внутренней структуры
  * Износостойкость высокая
  * Легко обрабатывается любым механическим способом: резка, шкурение, раскрой и прочее
  * Гипоаллергенен


![](https://evaline.com.ua/images/1.2b2b.jpg.pagespeed.ce.PsqT0wLd8s.jpg)

## Характеристики ЭВА листов

  * Материал: вспененный этиленвинилацетат / EVA (ЭВА - этиленвинилацетат).
  * Толщина листов от 2 мм (шаг в 0.1 мм).
  * Цвет: оранжевый, красный, черный, желтый, синий, зеленый, хаки и другие.
  * Уточняйте наличие и размеры.
