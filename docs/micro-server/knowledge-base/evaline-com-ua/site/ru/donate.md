# Каремат кожному солдату України!

У воєнний час каремати стали невід’ємним атрибутом для кожного солдата української армії, адже вони створюють умови для сну і допомагають зберегти здоров’я, так як мають низьку теплопровідність і вологостійкість. 

Наша компанія спеціалізується на виробництві ЕВА-продукції. Тому з перших днів війни ми передавали спальні ЕВА-килимки та сидіння, які були в наявності, армії і теробороні України. За перший місяць декілька тисяч карематів надійшли адресатам. Ми вже отримали позитивні відгуки і надалі налаштовані постачати нашу продукцію армії.
