# Як відрізнити EVA-листи для виробництва автомобільних килимків вітчизняного виробництва від закордонного?

30.10.2020

  * Зарубіжні листи можуть мати різкий неприємний запах.
  * Під час механічного впливу місце контакту відновлюється дуже повільно.
  * Товщина листа EVA від вітчизняного виробника чітко коливається від 9 до 10 мм, товщина зарубіжних листів дорівнює 9-12 мм, що не дуже зручно при подальшій окантовці автокилимів. Через глибоку "комірку" нижня сторона листа тонка, тому за найменшої його деформації бруд і вода можуть потрапити на ковролін.
  * На дотик зарубіжний матеріал менш пружний.
  * За дуже низьких або високих температур піддається деформації.
  * Ціна на даний товар нижча ринкової.
