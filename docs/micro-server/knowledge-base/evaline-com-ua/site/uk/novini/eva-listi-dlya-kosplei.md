# ЕВА-листи для створення костюмів різної складності

10.02.2022

Популярний напрямок косплей, який полягає у створенні костюмів та перевтіленні у персонажів комп'ютерних ігор, кінематографа, літератури, коміксів та аніме, набирає все більше обертів в Україні та за кордоном.

Одним з основних матеріалів для створення образів є спінений полімер етиленвінілацетат (ЕВА, EVA foam, пінка, фоаміран), який компанія «EVA-line» випускає в листах різної щільності, твердості, товщини та палітри кольорів.

## Переваги ЕВА-матеріалу для косплей костюмів

Завдяки оптимальному поєднанню показників твердості, щільності та гнучкості ЕВА є чудовим матеріалом для втілення сміливих творчих ідей.

EVA foam має такі властивості: 

  * Легкість, гнучкість та висока міцність на розрив у масі.
  * Здатність EVA foam набувати потрібної форми під впливом високої температури.
  * Водонепроникність та гіпоалергенність матеріалу.
  * Можливість легко фарбувати, склеювати і зшивати елементи.


За допомогою ЕВА-матеріалу можна виготовляти костюми різної складності та масштабу – формувати дрібні деталі та створювати великогабаритні конструкції. Цінність матеріалу EVA foam визнана майстрами по всьому світу.

## Характеристики ЕВА-листів

Для створення різних елементів костюма може знадобитися матеріал різної твердості, щільності та товщини. Співвідношення цих величин можна побачити у таблиці.

![EVA foam листи характеристика](https://evaline.com.ua/images/news/157/foam-schema2.svg)

Мінімальна товщина листа 2 мм, максимальна – 35 мм. Різка здійснюється з кроком в 1 мм.
