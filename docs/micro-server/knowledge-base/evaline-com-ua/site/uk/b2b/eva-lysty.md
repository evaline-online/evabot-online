# Виробництво EVA (ЕВА) листів для оптових покупців

EVA (ЕВА) листи - це зручний матеріал для костюмів та інших аксесуарів ручної роботи (до таких відносяться костюми для косплей, крафту, різні бутафорські костюми, декорації).

ЕVA (етиленвінілацетат) - це екологічно чистий спінений етиленвінілацетат - композиційно полімерний матеріал, що відноситься до поліолефінів.

![](https://evaline.com.ua/images/x1.1b2b.jpg.pagespeed.ic._uXpqEEWCJ.jpg)

### Широка колірна гамма

Усі позиції мають широку кольорову гаму, що дозволить Вам якнайкраще підібрати матеріал саме для себе.

### Переваги даного матеріалу

  * Матеріал відрізняється легкістю (пориста структура), високою міцністю на розрив у масі, гнучкістю
  * Термопластичний - під часнагрівання зберігає форму, без руйнування своєї внутрішньої структури
  * Висока зносостійкість
  * Легко обробляється будь-яким механічним способом: різка, шкуріння, розкрій та інше
  * Гіпоалергенний


![](https://evaline.com.ua/images/1.2b2b.jpg.pagespeed.ce.PsqT0wLd8s.jpg)

## Характеристики ЕВА листів

  * Матеріал: спінений етиленвінілацетат / EVA (ЕВА - етиленвінілацетат)
  * Товщина листів від 2 мм (крок у 0.1 мм)
  * Колір: помаранчевий, червоний, чорний, жовтий, синій, зелений, хакі та інші.
  * Уточнюйте наявність і розміри.
