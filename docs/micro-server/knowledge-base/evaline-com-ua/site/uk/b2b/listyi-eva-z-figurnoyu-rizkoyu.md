# ЕВА листи з фігурною різкою

Фігурна різка – один із методів обробки ЕВА-матеріалу, за допомогою якого на поверхні листів можна створити оригінальні об'ємні візерунки різної складності. Через фігурну різку можна пропускати одношарові або багатошарові ламіновані ЕВА-листи. З таким матеріалом легко працювати – він легко ріжеться за допомогою канцелярського ножа, вирубується штанцформами, шкуриться та клеїться. Рельєфна текстура у поєднанні з яскравою кольоровою гамою матеріалу роблять вироби яскравими та унікальними.

![](https://evaline.com.ua/images/xtisnenie-textura.jpg.pagespeed.ic.Bh61skiAKQ.jpg)

### Унікальна текстура

Вироби з ЕВА нашого виробництва виходять барвистими та яскравими, приємними на дотик.

### Екологічна чистота та безпека

Матеріал не має стороннього запаху та безпечний для людини.

![](https://evaline.com.ua/images/xflisty-eco.jpg.pagespeed.ic.Xr4m23TVie.jpg)

![](https://evaline.com.ua/images/xlisty-vlaga.jpg.pagespeed.ic.WLaeRkexPU.jpg)

### Водонепроникність

ЕВА не вбирає вологу і не накопичує неприємні запахи через закриту пористу структуру.

### Різноманітність кольорів

Величезний спектр кольорів та відтінків дає можливість підібрати матеріал для вирішення практично будь-яких завдань.

![](https://evaline.com.ua/images/xtisnenie-tsveta.jpg.pagespeed.ic.btuiTjLCUW.jpg)

![](https://evaline.com.ua/images/xtisnenie-legkost.jpg.pagespeed.ic.4oVQ4vRnJp.jpg)

### Легкість

Легкість матеріалу дозволяє не обтяжувати кінцевий виріб.

### Фігурні листи також можна обтягувати шкірою, екошкірою та текстилем. 

Згодом такий матеріал використовують для ложементів, у взуттєвій сфері - для устілок літнього відкритого взуття, а також для водонепроникних калош та чобітків.
