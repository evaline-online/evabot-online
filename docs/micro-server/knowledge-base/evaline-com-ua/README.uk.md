# Архів сайту EvaLine у форматі Markdown

Повна структурована конвертація веб-сайту компанії EvaLine усіма мовами у формат Markdown:
- 🇺🇦 **Українська**: `site/uk/` (43 сторінки з `evaline.com.ua`)
- 🌐 **Російська**: `site/ru/` (67 сторінок з `evaline.com.ua/ru/`)
- 🇬🇧 **Англійська**: `site/en/` (34 сторінки з `eva-line.com`)
- 🇵🇱 **Польська**: `site/pl/` (31 сторінка з `eva-line.pl`)
- 🇩🇪 **Німецька**: `site/de/` (1 сторінка з `de.eva-line.com`)
- 🇷🇴 **Румунська**: `site/ro/` (1 сторінка з `ro.eva-line.com`)

**Всього сконвертовано:** 177 сторінок контенту + 1 зведений навігаційний індекс `SUMMARY.md`.

---

## Ключові можливості

1. **Сучасний пайплайн конвертації в Markdown**:
   - Реалізовано на Python з використанням DOM-парсингу на базі BeautifulSoup4, `html2text` та PyYAML.
   - Збережено ієрархію заголовків, таблиці характеристик, списки продукції, галереї зображень та контактні блоки менеджерів.
2. **Обробка лінивого завантаження PageSpeed**:
   - Автоматичне визначення та обробка атрибутів відкладеного завантаження (`data-pagespeed-lazy-src`), що усунуло ризик втрати картинок і заміни їх на заглушки (`1.JiBnMqyl6S.gif`).
3. **Структурований YAML Frontmatter**:
   - Кожен файл містить метадані: `title`, `description`, вихідний `url`, `lastmod`, `og_image`, `language`, `language_name`, `category` та відносний шлях `file`.
4. **Перелінковка внутрішніх посилань**:
   - Внутрішні посилання `.html` перетворені на відносні посилання на Markdown-файли (`.md`), що забезпечує зручну офлайн-навігацію в Obsidian, Foam, GitHub та будь-яких Markdown-переглядачах.
5. **Єдиний мультимовний каталог**:
   - Файл `site/SUMMARY.md` містить зміст усього архіву з групуванням за мовами та категоріями (`b2b`, `b2c`, `news`, `general`).

## Структура каталогів

```text
.
├── site/
│   ├── SUMMARY.md                # Зведений зміст усіма 6 мовами
│   ├── conversion_stats.json     # Детальний журнал аудиту всіх сторінок
│   ├── uk/                       # Українська версія (43 файли)
│   ├── ru/                       # Російська версія (67 файлів)
│   ├── en/                       # Англійська версія (34 файли)
│   ├── pl/                       # Польська версія (31 файл)
│   ├── de/                       # Німецька версія (1 файл)
│   └── ro/                       # Румунська версія (1 файл)
├── scripts/
│   └── convert_evaline.py       # Автоматичний скрипт краулінгу та конвертації
├── README.en.md                  # Документація (англійська)
├── README.ru.md                  # Документація (російська)
├── README.uk.md                  # Документація (українська)
├── REPORT.en.md                  # Звіт про аудит і конвертацію (англійська)
├── REPORT.ru.md                  # Звіт про аудит і конвертацію (російська)
└── REPORT.uk.md                  # Звіт про аудит і конвертацію (українська)
```
