# Архив сайта EvaLine в формате Markdown

Полная структурированная конвертация веб-сайта компании EvaLine на всех языках в формат Markdown:
- 🇺🇦 **Украинский**: `site/uk/` (43 страницы с `evaline.com.ua`)
- 🌐 **Русский**: `site/ru/` (67 страниц с `evaline.com.ua/ru/`)
- 🇬🇧 **Английский**: `site/en/` (34 страницы с `eva-line.com`)
- 🇵🇱 **Польский**: `site/pl/` (31 страница с `eva-line.pl`)
- 🇩🇪 **Немецкий**: `site/de/` (1 страница с `de.eva-line.com`)
- 🇷🇴 **Румынский**: `site/ro/` (1 страница с `ro.eva-line.com`)

**Всего сконвертировано:** 177 страниц контента + 1 сводный навигационный индекс `SUMMARY.md`.

---

## Ключевые возможности

1. **Современный пайплайн конвертации в Markdown**:
   - Реализован на Python с использованием DOM-парсинга на базе BeautifulSoup4, `html2text` и PyYAML.
   - Сохранена иерархия заголовков, таблицы характеристик, списки продукции, галереи изображений и контактные блоки менеджеров.
2. **Обработка ленивой загрузки PageSpeed**:
   - Автоматическое определение и обработка атрибутов отложенной загрузки (`data-pagespeed-lazy-src`), что предотвратило потерю картинок и замену их на заглушки (`1.JiBnMqyl6S.gif`).
3. **Структурированный YAML Frontmatter**:
   - Каждый файл снабжен метаданными: `title`, `description`, исходный `url`, `lastmod`, `og_image`, `language`, `language_name`, `category` и относительный путь `file`.
4. **Перелинковка внутренних ссылок**:
   - Внутренние ссылки `.html` преобразованы в относительные ссылки на Markdown-файлы (`.md`), что обеспечивает удобную оффлайн-навигацию в Obsidian, Foam, GitHub и любых Markdown-редакторах.
5. **Единый мультиязычный каталог**:
   - Файл `site/SUMMARY.md` содержит оглавление всего архива с группировкой по языкам и категориям (`b2b`, `b2c`, `news`, `general`).

## Структура каталогов

```text
.
├── site/
│   ├── SUMMARY.md                # Сводное оглавление по всем 6 языкам
│   ├── conversion_stats.json     # Детальный журнал аудита всех страниц
│   ├── uk/                       # Украинская версия (43 файла)
│   ├── ru/                       # Русская версия (67 файлов)
│   ├── en/                       # Английская версия (34 файла)
│   ├── pl/                       # Польская версия (31 файл)
│   ├── de/                       # Немецкая версия (1 файл)
│   └── ro/                       # Румынская версия (1 файл)
├── scripts/
│   └── convert_evaline.py       # Автоматический скрипт краулинга и конвертации
├── README.en.md                  # Документация (английский)
├── README.ru.md                  # Документация (русский)
├── README.uk.md                  # Документация (украинский)
├── REPORT.en.md                  # Отчет об аудите и конвертации (английский)
├── REPORT.ru.md                  # Отчет об аудите и конвертации (русский)
└── REPORT.uk.md                  # Отчет об аудите и конвертации (украинский)
```
