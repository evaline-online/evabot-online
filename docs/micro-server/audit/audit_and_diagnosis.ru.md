**Дата:** 3 сентября 2026 г.  
**Аккаунт:** `evabot.online@gmail.com`  
**Проект GCP:** `evabot-agent-server` (Номер проекта: `873069440066`)  
**Стандарты расчетов:** Исключительно в долларах США ($) и евро (€)  

---

## 1. Краткое резюме

Проведена комплексная диагностика проекта Google Cloud `evabot-agent-server`. В инфраструктуре задействованы два активных инстанса Compute Engine:
1. **`evabot-agent-vm`** во Франкфурте (`europe-west3-a`) — мощный вычислительный узел (`c3-standard-8`, 32 ГБ DDR5 RAM, 100 ГБ NVMe).
2. **`evaline-micro-vm`** в Айове (`us-central1-a`) — веб-шлюз и маршрутизатор доменов (`e2-micro`, 1 ГБ RAM + подключенный swap 2 ГБ, 20 ГБ диск), на котором работает веб-сервер Caddy и хостятся домены, включая `evabot.online`.

Предыдущая реализация в `/var/www/evabot.online` представляла собой демонстрационный макет с фиктивными ответами без настоящего подключения к API Gemini. Предыдущая кодовая база заархивирована на сервере (`/var/www/evabot.online_pre_gemini_backup_20260903_150219.tar.gz`) и локально (`legacy_archive/evabot_v001_initial_snapshot.tar.gz`).

## 2. Инвентаризация серверов и анализ ресурсов

### 2.1 Сервер 1: `evabot-agent-vm` (Вычислительный узел во Франкфурте)
- **Зона:** `europe-west3-a`
- **Тип машины:** `c3-standard-8` (8 vCPU Intel Sapphire Rapids, 32 ГБ DDR5 RAM)
- **Внешний IP:** `34.179.253.183`
- **Внутренний IP в VPC:** `10.156.0.2`
- **Диски:**
  - `persistent-disk-0`: 50 ГБ загрузочный NVMe (`/`)
  - `persistent-disk-1`: 50 ГБ подключенный NVMe (`/data`)
- **Операционная система:** Debian 12 (Bookworm), ядро Linux 6.1
- **Активные сервисы:** Nginx, Code-Server (`code-server@evabot.service`), Tailscale, служба SSH
- **Использование ресурсов:** Нагрузка CPU 0.00, свободно ~30 ГБ RAM.

### 2.2 Сервер 2: `evaline-micro-vm` (Веб-сервер и доменный шлюз в Айове)
- **Зона:** `us-central1-a`
- **Тип машины:** `e2-micro` (2 vCPU burstable, 1 ГБ RAM, настроен swap 2 ГБ)
- **Внешний IP:** `136.114.26.252`
- **Внутренний IP в VPC:** `10.128.0.2`
- **Диски:**
  - `persistent-disk-0`: 20 ГБ SCSI (`/`, занято 3.9 ГБ, свободно 15 ГБ)
- **Операционная система:** Debian 12 (Bookworm), ядро Linux 6.12
- **Установленные среды выполнения:** Node.js v20.20.2, npm 10.8.2, Git 2.47.3, Python 3.11, веб-сервер Caddy
- **Активные сервисы:**
  - Веб-сервер Caddy (порты 80 и 443 с автоматическим выпуском сертификатов Let's Encrypt TLS)
  - TigerVNC (`Xtigervnc` на порту 5901 с графической оболочкой XFCE4)
  - Агент узла Tailscale
  - Служба SSH, systemd
- **Веб-домены, настроенные в Caddy:**
  - `evabot.online` и `www.evabot.online` (каталог `/var/www/evabot.online`)
  - `evaline.website` и `www.evaline.website` (каталог `/var/www/evaline.website`)
  - `evaline.online` и `www.evaline.online` (каталог `/var/www/evaline.online`)
  - `evaline.network` и `www.evaline.network` (каталог `/var/www/evaline.network`)

## 3. Анализ прежней версии EvaBot

В каталоге `/var/www/evabot.online` находился начальный прототип (`v0.0.1`):
1. **Фиктивные ответы:** Генерировался шаблонный заглушечный текст вместо реальных запросов к Gemini.
2. **Статичный Canvas:** Каркасная 3D-сетка лица и синтетические графики телеметрии.
3. **Отсутствие функций LLM:** Не было клиента потоковой генерации, переключателя моделей и сохранения контекста диалога.
4. **Резервное копирование:**
   - Резервная копия на микросервере: `/var/www/evabot.online_pre_gemini_backup_20260903_150219.tar.gz`
   - Локальный архив: `legacy_archive/evabot_v001_initial_snapshot.tar.gz`

## 4. Архитектурная карта нового модульного чата

1. **Двойная среда выполнения:**
   - Универсальный скрипт на TypeScript, работающий в любом терминале (CLI REPL и флаги аргументов) и веб-браузере.
2. **Интеграция с Google AI Pro / Gemini API:**
   - Выбор моделей: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-1.5-pro`.
   - Потоковая передача токенов через SSE / ReadableStream.
3. **Легковесный демон для микросервера:**
   - Потребление памяти менее 40 МБ RAM.
   - Маршрутизация через Caddy reverse proxy (`/api/*` на локальный демон).
4. **Тестирование и логирование:**
   - Автоматические тесты (`npm test`) и структурированное логирование в файл и консоль.
