# Модульна архітектура та технічна специфікація EvaBot

**Версія:** 0.2.0  
**Статус:** Активна  
**Стандарти розрахунків:** Виключно долари США ($) та євро (€)  

---

## 1. Загальний огляд системи

EvaBot — це модульний TypeScript-додаток, розроблений для взаємодії з мовними моделями Google Gemini (за підпискою Google AI Pro). Архітектура системи забезпечує одночасну та ефективну роботу як у будь-якому терміналі (CLI), так і в сучасних веб-браузерах.

---

## 2. Основні модулі

### 2.1 `src/models/ModelRegistry.ts`
Централізований каталог підтримуваних моделей Google Gemini з метаданими, обмеженнями контексту та рівнями продуктивності:
- `gemini-2.5-flash`: Основна рекомендована модель для швидкого інтерактивного діалогу.
- `gemini-2.5-pro`: Флагманська модель для складного логічного аналізу, кодування та міркувань.
- `gemini-2.0-flash`: Модель нового покоління з ультранизькою затримкою.
- `gemini-1.5-pro`: Модель для обробки надвеликих обсягів контексту.
- `gemini-1.5-flash`: Швидка та ресурсоефективна модель.

### 2.2 `src/core/GeminiClient.ts`
Клієнт без зовнішніх залежностей, що напряму працює з REST API Google Generative Language:
- Звичайна генерація відповіді через `/v1beta/models/{model}:generateContent`.
- Потокова генерація токенів у реальному часі через Server-Sent Events (SSE): `/v1beta/models/{model}:streamGenerateContent?alt=sse`.
- Повна кросплатформна сумісність між Node.js 18+ та веб-браузерами.

### 2.3 `src/core/ChatSession.ts`
Керує станом бесіди, історією повідомлень, автоматичним обмеженням довжини контексту, перемиканням активної моделі без втрати історії та системними підказками (system instruction).

### 2.4 `src/core/Logger.ts`
Структуроване логування з кольоровим виведенням ANSI в термінал та збереженням записів у файл `logs/evabot.log`.

### 2.5 `src/server/server.ts`
Легковаговий HTTP-сервер на вбудованих засобах Node.js:
- Роздає файли веб-інтерфейсу.
- Відповідає на запити `/api/health`, `/api/models`, `/api/chat`, `/api/chat/stream`.
- Споживає менше 25 МБ RAM, що ідеально підходить для мікросервера `e2-micro`.

## 3. Топологія розгортання

1. **`evaline-micro-vm` (`e2-micro`, Айова):**
   - Caddy здійснює TLS-термінацію (порти 80/443).
   - Перенаправляє виклики `/api/*` на `localhost:3000`, де запущено службу `evabot-chat.service`.
   - Забезпечує статичну доставку файлів сайту.
   - Створено файл підкачки (Swap) розміром 2 ГБ для запобігання дефіциту пам'яті.

2. **`evabot-agent-vm` (`c3-standard-8`, Франкфурт):**
   - Використовується для важких фонових обчислень, кодової бази та роботи з монтованим диском `/data`.
