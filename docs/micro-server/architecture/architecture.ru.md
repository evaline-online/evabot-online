# Модульная архитектура и техническая спецификация EvaBot

**Версия:** 0.2.0  
**Статус:** Активна  
**Стандарты расчетов:** Исключительно доллары США ($) и евро (€)  

---

## 1. Обзор системы

EvaBot — это модульное TypeScript-приложение, предназначенное для взаимодействия с искусственным интеллектом на базе Google Gemini (подписка Google AI Pro). Архитектура обеспечивает одновременную работу как в консоли любого терминала (CLI), так и в современных веб-браузерах.

---

## 2. Основные модули

### 2.1 `src/models/ModelRegistry.ts`
Централизованный каталог поддерживаемых моделей Google Gemini с метаданными, лимитами токенов и классификацией уровней:
- `gemini-2.5-flash`: Основная рекомендуемая модель для быстрых интерактивных диалогов.
- `gemini-2.5-pro`: Флагманская модель для сложного анализа, рассуждений и написания программного кода.
- `gemini-2.0-flash`: Модель следующего поколения с минимальной задержкой ответа.
- `gemini-1.5-pro`: Поддержка сверхдлинного контекста.
- `gemini-1.5-flash`: Экономичная высокоскоростная модель.

### 2.2 `src/core/GeminiClient.ts`
Клиент без сторонних зависимостей, напрямую взаимодействующий с REST API Google Generative Language:
- Обычная генерация через `/v1beta/models/{model}:generateContent`.
- Потоковая генерация в реальном времени через Server-Sent Events (SSE): `/v1beta/models/{model}:streamGenerateContent?alt=sse`.
- Полная совместимость между Node.js 18+ и веб-браузерами.

### 2.3 `src/core/ChatSession.ts`
Управляет сессией диалога, сохранением истории сообщений, автоматическим усечением длины контекста для предотвращения переполнения токенов, динамическим переключением моделей без потери контекста и системными инструкциями.

### 2.4 `src/core/Logger.ts`
Структурированный логер с выводом форматированных ANSI-сообщений в консоль и записью логов с временными метками в файл `logs/evabot.log`.

### 2.5 `src/server/server.ts`
Легковесный HTTP-сервер на базе стандартных модулей Node.js:
- Раздает статические файлы веб-интерфейса.
- Предоставляет эндпоинты `/api/health`, `/api/models`, `/api/chat`, `/api/chat/stream`.
- Потребляет менее 25 МБ RAM, идеально вписываясь в ресурсы микросервера `e2-micro`.

## 3. Топология развертывания

1. **`evaline-micro-vm` (`e2-micro`, Айова):**
   - Caddy выполняет роль внешнего TLS-терминатора (порты 80/443).
   - Проксирует запросы `/api/*` на `localhost:3000`, где работает служба `evabot-chat.service`.
   - Раздает статические скомпилированные файлы веб-интерфейса.
   - Подключен файл подкачки (Swap) 2 ГБ для стабильности памяти.

2. **`evabot-agent-vm` (`c3-standard-8`, Франкфурт):**
   - Выделен для ресурсоемких задач, среды code-server и постоянного дискового хранилища (`/data`).
