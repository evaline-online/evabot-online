💬 Request Flow (How a Message Travels)

1. 👤 User Input → Message sent from browser to EvaFace
2. 🛡️ Security Check → IP blocklist + rate limit + suspicious path detection
3. 🔌 Plugin Router → PluginManager dispatches to right plugin
4. 🧠 Plugin Handler → ChatRouter / KB / Consilium processes request
5. 🌐 LLM Provider → Forwarded to Google/OmniRoute/OpenRouter/OpenCode
6. 📝 Response → Streamed back through EvaFace to User
7. 📊 Log → Logged in logs/evabot.log with IP, duration, model
