03The layer being built

An AI agent factory on top of the polymer factory.

An agent is not a chat window. It is a digital co-worker with a role, memory, tools and an audit trail. Four layers turn a model into a worker.

L4

Agent runtimes

Hermes, OpenClaw, agy and the opencode / kilo / qwen set. Different agents for different jobs, each with its own character and strengths.

6
L3

Single model gateway

OmniRoute: one OpenAI-compatible endpoint (LiteLLM). All 94 models sit behind a single door, so switching a provider never means rewriting agents.

1
L2

MCP tool bus

21 servers, with 8 wired into every runtime. Files, Git, GitHub, databases, browser and memory — this is how agents get hands.

21
L1

Memory

Graph memory, SQLite full-text search and a vector store. Every answer is grounded in real documents rather than guesswork.

RAG

Closed execution loop

Perceive, plan, execute in an isolated sandbox, review, and roll back automatically on error — with no human copying text between screens.

No vendor lock-in

94 models and 36 routes. If a provider slows down or changes terms, traffic moves to another in milliseconds.

Quality gates

Contested decisions are cross-checked by independent models before they ever reach the plant floor.

04The network

Two nodes: a shield at the edge, a brain in the core.

A lightweight node takes the public traffic. Heavy computation runs in a protected core. The two are joined by a private encrypted tunnel.

If one node goes down, the other keeps serving.

Data isolation

Internal traffic stays inside the private network. The public internet only sees the entry point.

Continuity

Different providers and different nodes. One failing element does not stop orders or calculations.

05Consilium-30

Thirty specialised agents that debate before they decide.

A single model can be confidently wrong. Consilium-30 sends one task to thirty roles across five groups, then an arbiter synthesises the agreed decision.

Four base roles rotate and converge into one balanced centre — the arbiter.
